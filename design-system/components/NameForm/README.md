# NameForm

Single-field form to save a score under a name.

## Rules
- Input: glass fill, 2px `night-700` border that turns `ember` on focus, `radius-md`, `body` text at 1.1rem.
- Submit: solid `pumpkin` with `ink-on-pumpkin`, `radius-md`, `tap-min` tall. Label "Save".
- Max 10 characters; blank saves as "Anon". The input is the only selectable text in the app.
