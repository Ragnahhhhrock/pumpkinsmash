# GameOver

The end-of-round summary: ghost, headline, final score, and a badge when it is a new best.

## Rules
- Headline in `headline` style, `blood` with `blood-shadow` drop — the only big red on any screen.
- Final score in `score-final`, `ember`, `shadow-glow-ember`.
- The badge (`gold` → `ember` gradient, `ink-on-pumpkin` text) appears only for a new personal best, and pulses.
- Follow with the name form, then primary "Play again" and secondary "Home".
